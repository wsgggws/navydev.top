# Scene 01

## Title

The Hacker

## Story

A software engineer sits in a dark room.

Only the monitor lights his face.

A Vim window is open.

The cursor blinks.

He types Python code.

The terminal switches.

Now Go code appears.

He continues typing.

Rain falls outside.

The camera slowly zooms toward the monitor.

Fade to black.

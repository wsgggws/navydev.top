# Scene 02

## Title

The Terminal

## Story

Black screen. Static.

A CRT terminal flickers on. Phosphor green text.

Cursor blinks. We type:

```
$ whoami
尚未秃头，头发上撸的攻城狮🦁
```

Then:

```
$ echo "motto"
代码爱干净，码码要洗手
```

Then the screen scrolls, scanlines drift.

Fade out.
